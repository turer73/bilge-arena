# R4.1 — Kağıt Modu ve Çevrimdışı Tekrar Paketi

**Tarih:** 2026-08-09
**Kapsam:** Mevcut “Bugünün 15’i” planından owner-only yazdırılabilir/PDF paket, QR cevap girişi, optik form ve mobil karalama alanı
**Durum:** Ürün/veri sözleşmesi, yerel uygulama, gerçek PostgreSQL doğrulaması, masaüstü/mobil erişilebilirlik QA'sı ve bağımsız Terra incelemesi tamamlandı. Commit/PR, canlı migration, pilot ve deploy yapılmadı.

## Ürün sınırı

R4.1 yeni soru seçme motoru veya ödül kanalı kurmaz. Kullanıcının o gün için sunucuda dondurulmuş `daily_plan + daily_plan_items` planı, fiziksel çalışmaya uygun tek bir kağıt paketine çevrilir.

- Paket yalnız authenticated owner tarafından oluşturulur, görüntülenir ve gönderilir.
- Paket `1–15` günlük plan sorusunu immutable public soru snapshot'ı olarak saklar; doğru cevap/çözüm aktif pakette hiçbir public yanıta çıkmaz.
- “PDF indir” pilotta tarayıcının yazdırma/“PDF olarak kaydet” akışıdır. Özel HTML veya API yanıtı service worker cache'ine yazılmaz; çevrimdışı artefakt kullanıcının kaydettiği PDF veya bastığı kağıttır.
- Yazdırılabilir optik form aynı pozisyonları içerir. QR yalnız owner-auth gerektiren cevap giriş URL'sini taşır; cevap, kullanıcı, plan veya soru içeriği QR içine gömülmez.
- Mobil karalama alanı yalnız cihaz belleğindeki canvas'tır; sunucuya, analytics'e veya kalıcı browser storage'a çizim göndermez.
- Kağıt cevapları server-authoritative doğru seçenek snapshot'ına göre notlandırılır; cevap anahtarı ancak final submit sonrasında açılır.
- Kağıt kanıtı gözetimsiz/self-entered olduğu için mastery'ye `0.5` ağırlıkla girer. `v2` verified metriklerini, FSRS zamanlamasını, verified attempt/session'ı, XP, coin, görev, seri, rozet, sosyal puan veya reward ledger'ı değiştirmez.

Pilot iki varsayılan-kapalı anahtara bağlıdır:

- `PAPER_MODE_ENABLED=false`;
- `NEXT_PUBLIC_PAPER_MODE_ENABLED=false`.

## Veritabanı sözleşmesi — migration 104

Private/RLS tablolar:

- `paper_study_packs`: owner, kaynak günlük plan, request-id, `active|submitted`, oluşturma/son kullanma/gönderme zamanı ve canonical submit sonucu.
- `paper_study_pack_items`: pozisyon, question id, game/kategori/konu/zorluk ve public question content snapshot'ı; private doğru seçenek; final seçim/doğruluk.
- `paper_study_pack_item_outcomes`: issue anındaki aktif outcome/mapping snapshot'ı.
- `paper_study_pack_submission_requests`: request/payload hash ve canonical replay sonucu.
- `paper_outcome_evidence`: submitted, non-blank cevapların immutable `0.5 × mapping_weight` mastery deltas'ı.

Tüm tablolar RLS açık ve `PUBLIC/anon/authenticated/service_role` doğrudan yazımına kapalıdır. Service role yalnız owner-scoped SECURITY DEFINER RPC'leri çağırır:

1. `issue_paper_study_pack(uuid,uuid,uuid)` — `(user, plan, request)`; exact günlük-plan owner guard, request replay/mismatch ve immutable item/outcome snapshot.
2. `get_my_paper_study_pack(uuid,uuid)` — `(user, pack)`; aktif pakette cevap anahtarı yok, submitted pakette yalnız owner'ın seçim/not sonucu.
3. `submit_paper_study_pack(uuid,uuid,jsonb,uuid)` — `(user, pack, answers, request)`; tüm pozisyonları bir kez kabul eder, null seçimi boş sayar, server snapshot'ıyla notlandırır, plan completion union'ını ve `0.5` paper mastery delta'sını atomik/idempotent uygular.

Pack issue süresi `7 gün`; expired aktif paket submit edilemez. Aynı issue/submit request-id aynı payload ile canonical replay döndürür, farklı payload `22023`; ikinci farklı submit çatışmadır. DB hiçbir paper işleminde `verified_attempts`, `game_sessions`, `session_answers`, FSRS tabloları, XP/coin, quest, streak, achievement, league contribution veya reward ledger yazmaz.

## Public JSON ve API

`POST /api/study/paper-packs` body:

```text
{ game, examRef: string|null, requestId: uuid }
```

Server owner'ın İstanbul günündeki exact planını bulur ve issue RPC'sini çağırır. Yanıt yalnız `packId`, durum/zamanlar, `itemCount` ve `replayed` taşır.

`GET /api/study/paper-packs/:packId`:

```text
{
  packId, status, createdAt, expiresAt, submittedAt,
  plan: { game, planDate, examRef },
  items: [{
    position,
    question: { id, game, category, topic, difficulty, content: { question, options, sentence?, passage?, context?, type? } },
    selectedOption: integer|null,
    isCorrect: boolean|null,
    correctOption: integer|null
  }],
  summary: null|{ answeredCount, correctCount, scorePercent },
  mastery: { source: "paper", weight: 0.5 },
  reward: { xp: 0, coins: 0, socialPoints: 0 },
  privacy: { ownerOnly: true, privateCacheDisabled: true }
}
```

Aktif pakette `selectedOption/isCorrect/correctOption` null'dır. Submitted pakette sonuç alanları doludur; boş bırakılmış pozisyonda selection ve correctness null kalır. UUID olarak yalnız owner'ın UI navigasyonu için pack ve question id'leri vardır; başka kullanıcı/attempt/session/plan/outcome id'si yoktur.

`POST /api/study/paper-packs/:packId/submit` body:

```text
{
  requestId: uuid,
  answers: [{ position: 1..15, selectedOption: integer|null }]
}
```

Üç endpoint server flag + auth + owner/user rate-limit + strict Zod + `Cache-Control: private, no-store` uygular. Client user/plan/question/correct-answer/mastery-weight seçemez.

## UI ve erişilebilirlik

- “Bugünün 15’i” kartında public flag açıkken ikincil “Kağıt/PDF” bağlantısı görünür.
- Hazırlama ekranı fiziksel çalışma/no-reward sınırını açıkça anlatır ve explicit kullanıcı eylemiyle paketi üretir.
- Paket ekranında başlık, soru metni/seçenekler, sayfa kırılmalarına uygun kartlar, optik form, kısa paket kodu, QR ve yazdır/“PDF kaydet” CTA'sı vardır.
- Cevap ekranı her soru için native radio group, boş bırak seçeneği, submit öncesi özet, final doğru/yanlış geri bildirimi ve yerel karalama canvas'ı sunar.
- Scratchpad klavye kullananlar için “Temizle” düğmesi ve çizimin kaydedilmediğini belirten metin taşır; cevap girişi canvas'a bağlı değildir.
- Normal metin kontrastı en az `4.5:1`, dokunma hedefleri en az `44px`, 390 px mobilde yatay taşma yok; print preview'da navigasyon/CTA gizlenir.

- Saf sözleşme: strict JSON, aktif cevap-sızıntısı yasağı, submitted invariant'ları, skor matematiği, bounds ve reward-zero.
- Statik SQL + disposable PostgreSQL: owner/plan guard, snapshot, replay/mismatch, expiry, cevap notlandırma, blank, plan union, `0.5` mastery idempotency, no verified/reward/social write, ACL/RLS.
- API/hook/UI: çift flag, auth/rate/no-store, UUID/body sınırı, loading/error/retry, print/QR/optik, native answer groups, submit/replay ve scratchpad local-only.
- Service worker regression: özel kağıt navigasyonu network-only; request veya private HTML runtime/static cache'e yazılmaz.
- Type-check, hedef/tam Vitest, scoped/tam ESLint, migration lint, DB `node --check`, `git diff --check`, masaüstü/mobil/açık/koyu/print QA ve bağımsız Terra P0/P1 kapanışı.
