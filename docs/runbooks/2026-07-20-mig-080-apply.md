# Migration 080 Apply Runbook

**Migration:** `database/migrations/080_grant_multiplayer_stats_service_role_only.sql`
**Amaç:** `grant_multiplayer_stats` RPC'sinin `authenticated`'a açık EXECUTE yetkisini kaldırmak — kod tarafı (PR #270, `23a043b`, master'a merge edildi) canlıda ama bu migration **elle uygulanana kadar** DB'deki eski `(TEXT, BOOLEAN)` imzalı, `authenticated`'a açık fonksiyon hâlâ çalışır durumda. Kod merge = Vercel'de app-kodu deploy oldu; DB migration ayrı, elle adım.
**Risk:** Apply gecikirse RPC hâlâ istismar edilebilir (kritik-önem). Apply sırasında hata olursa `/api/multiplayer/grant-stats` route'u kırılır (yeni imza yoksa `svc.rpc('grant_multiplayer_stats', {p_user_id, ...})` "function not found" döner) — ama bu route'un çağrıldığı tek yer oda-bitişi sayaç senkronu, quiz/duello/skor akışını etkilemez (izole blast-radius).
**Geri alma:** Migration dosyasının sonundaki not GERİ ALMAYI ÖNERMEZ (güvenlik açığını yeniden açar). Route zaten yeni RPC imzasını çağırıyor — geri alınırsa route da bozulur, ayrıca eski route koduna dönmek gerekir.

Supabase Dashboard → SQL Editor:

```sql
-- Mevcut (eski) fonksiyonun imzası + grantee'leri
SELECT p.proname,
       pg_get_function_identity_arguments(p.oid) AS args,
       array_to_string(p.proacl, E'\n') AS acl
FROM pg_proc p
JOIN pg_namespace n ON n.oid = p.pronamespace
WHERE n.nspname = 'public' AND p.proname = 'grant_multiplayer_stats';
```
