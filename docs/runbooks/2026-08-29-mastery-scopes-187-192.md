## Read-only production preflight

```sql
SELECT game, upper(coalesce(exam_ref::text, '')) AS exam_ref,
       category::text AS category,
       count(*) FILTER (WHERE is_active) AS active_count
FROM public.questions
WHERE game IN ('turkce','sosyal')
  AND upper(coalesce(exam_ref::text, '')) = 'TYT'
GROUP BY game, upper(coalesce(exam_ref::text, '')), category::text
ORDER BY game, exam_ref, category;

WITH target_answer AS (
  SELECT DISTINCT attempt.id AS attempt_id, attempt.game,
         answer.id AS answer_id, answer.question_revision_id,
         question.id AS question_id, question.category::text AS current_category,
         upper(btrim(coalesce(question.exam_ref::text, ''))) AS current_exam_ref
  FROM public.verified_attempts AS attempt
  JOIN public.session_answers AS answer
    ON answer.session_id = attempt.session_id
   AND answer.user_id = attempt.user_id
  JOIN public.questions AS question ON question.id = answer.question_id
  WHERE attempt.game IN ('turkce','sosyal')
    AND attempt.completed_at IS NOT NULL
    AND attempt.session_id IS NOT NULL
    AND answer.question_id = ANY(attempt.question_ids)
    AND NOT coalesce(answer.is_skipped, false)
    AND question.is_active
    AND upper(btrim(coalesce(question.exam_ref::text, ''))) = 'TYT'
), checked AS (
  SELECT target.*,
         marker.attempt_id IS NULL AS marker_missing,
         snapshot.question_id IS NULL
           OR target.question_revision_id IS NULL
           OR snapshot.revision_id IS DISTINCT FROM target.question_revision_id
           OR snapshot.game IS DISTINCT FROM target.game
           OR upper(btrim(coalesce(snapshot.exam_ref, ''))) IS DISTINCT FROM 'TYT'
           OR snapshot.category IS DISTINCT FROM target.current_category
           AS snapshot_invalid
  FROM target_answer AS target
  LEFT JOIN public.mastery_materialized_attempts AS marker
    ON marker.attempt_id = target.attempt_id
  LEFT JOIN public.verified_attempt_question_revisions AS snapshot
    ON snapshot.attempt_id = target.attempt_id
   AND snapshot.question_id = target.question_id
)
SELECT game,
       count(DISTINCT attempt_id) FILTER (WHERE marker_missing)::integer AS marker_gap_attempts,
       count(*) FILTER (WHERE NOT marker_missing AND snapshot_invalid)::integer AS snapshot_gap_answers
FROM checked
GROUP BY game
ORDER BY game;
```

Required result: `marker_gap_attempts=0` and `snapshot_gap_answers=0` for both
games. A non-zero result is a stop condition, not permission to infer current
question metadata for historical answers.

## Failure compensation

Migration 189 publishes Turkish and 190 repairs historical evidence in the next
transaction. Migrations 191/192 always keep Social draft/no-op in this release;
reviewed source evidence alone cannot satisfy the deliberately missing
candidate-policy gate. If a repair fails after its preceding release committed,
hide that scope immediately with the prepared compensation below. Apply only to
the failed game, verify the resolver returns `NULL`, and investigate before any
retry.

```sql
BEGIN;
SET LOCAL lock_timeout = '10s';
SET LOCAL statement_timeout = '30s';
LOCK TABLE public.curriculum_scope_releases IN SHARE ROW EXCLUSIVE MODE;

DO $verify$
DECLARE
  -- Operator must replace this sentinel with exactly turkce or sosyal.
  v_failed_game text := 'REPLACE_WITH_turkce_OR_sosyal';
  v_taxonomy_version text;
  v_updated integer;
BEGIN
  IF v_failed_game NOT IN ('turkce','sosyal') THEN
    RAISE EXCEPTION 'invalid failed_game compensation target'
      USING ERRCODE = '22023';
  END IF;
  v_taxonomy_version := CASE v_failed_game
    WHEN 'turkce' THEN 'ba-tyt-turkce-v2'
    ELSE 'ba-tyt-sosyal-v1'
  END;

  UPDATE public.curriculum_scope_releases
  SET release_status = 'validating',
      diagnostic_enabled = false,
      updated_at = clock_timestamp()
  WHERE game = v_failed_game
    AND display_exam_ref = 'TYT'
    AND question_exam_ref = 'TYT'
    AND taxonomy_version = v_taxonomy_version
    AND release_status = 'released';
  GET DIAGNOSTICS v_updated = ROW_COUNT;
  IF v_updated <> 1 THEN
    RAISE EXCEPTION 'compensation target was not exactly one released scope'
      USING ERRCODE = '55000';
  END IF;

  IF public.resolve_released_curriculum_scope(v_failed_game, 'TYT') IS NOT NULL THEN
    RAISE EXCEPTION 'failed mastery scope is still public' USING ERRCODE = '23514';
  END IF;
END
$verify$;

NOTIFY pgrst, 'reload schema';
COMMIT;
```

Use `failed_game` only as `turkce` or `sosyal`. Record the exact migration hash,
error, compensation time and postcheck. Do not continue to the other subject
until the failed subject is hidden and the root cause is understood.

### Turkish v2 cutover is forward-only

After migration 189 commits, never manually change the Turkish registry back to
`ba-tyt-turkce-v1`. The live question mappings and any newly materialized
evidence are owned by v2; a registry-only reversal would make resolver,
mapping, and evidence lineage disagree.

If a post-commit Turkish v2 issue requires containment, first use the scoped
compensation above to hide v2. Preserve the v1 history snapshot and all v2
evidence. Remediate with a reviewed forward migration: retire the v2 scope when
appropriate, then create a corrected successor taxonomy/release and an explicit
snapshot-based evidence policy. Do not delete or relabel v1/v2 outcomes, or
copy evidence by mutable current question metadata.
